# FUnTiDES-lite Benchmarks

Run the project:

```bash
python3 scripts/benchmarks/run_benchmarks.py --threads 1,2,4,8 --runs 5
```

`--threads` selects thread counts; `--runs` selects repetitions per count. Without options: **4 threads, 3 runs**. The mesh is fixed at **10 × 10 × 10**.

## Terminal results

- **Simulation (Python clock):** elapsed time to run FUnTiDES, measured with `time.perf_counter()`.
- **TotalExe, Initial, Compute, Kernel, Output:** times reported by FUnTiDES itself. **Kernel is included in Compute.**
- **Snapshot / seismogram saving:** not measured yet (`0` is a placeholder).
- **Snapshot / seismogram visualization:** elapsed time of each visualization script, measured with `time.perf_counter()`.
- **Workflow:** time from starting FUnTiDES to finishing both visualizations (excluding benchmark graph generation).
- **File sizes:** sum of CSV/PNG file sizes, converted to MiB (`bytes / 1024²`).

The terminal displays the **average time across all runs** for each thread count.

## Output files

- `scripts/benchmarks/results/benchmarks.csv` — one row per run; previous results are kept.
- `scripts/benchmarks/plots/simulation_time.png` — average simulation time by thread count.
- `scripts/benchmarks/plots/workflow_time.png` — average workflow time by thread count.
- `scripts/benchmarks/plots/simulation_phases.png` — FUnTiDES phases by thread count.
- `scripts/benchmarks/plots/phase_times.png` — simulation and visualization phases by thread count.
- `scripts/benchmarks/plots/data_sizes.png` — measured file sizes.

To regenerate graphs without rerunning the simulations:

```bash
python3 scripts/benchmarks/plot_benchmarks.py
```

**Note:** Visualization currently uses existing test CSVs, not files generated by the benchmark simulation.
